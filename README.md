# 🧠 Skin Disease Detection Using AI

An AI-powered skin disease detection system using Convolutional Neural Networks (CNN).  
Users can upload a skin image and receive the predicted disease through a Flask-based web application.

## 🩺 Diseases Detected
- Cellulitis
- Impetigo
- Athlete Foot
- Nail Fungus
- Ringworm
- Cutaneous
- Chickenpox
- Shingles

## 🛠 Technologies Used
- Python
- TensorFlow / Keras
- Flask
- OpenCV
- NumPy
- HTML, CSS
